# نصب وابستگی‌ها

npm install

# کامپایل

npm run compile

# بسته‌بندی

npm run package

# انتشار (نیاز به Personal Access Token)

npm run publish

📋 قابلیت‌های نهایی
قابلیت توضیح
Command Palette ۱۲ دستور برای تمام عملیات Gitwe
Sidebar TreeView نمایش همه شاخه‌ها با نشان‌گذاری برنچ جاری، کلیک برای checkout
WebView Graph نمودار تعاملی با D3، کلیک برای finish/checkout
Status Bar نمایش برنچ جاری، تعداد شاخه‌ها، کلیک برای منوی سریع
تنظیمات workflow, configPath, autoPush, refreshInterval و ...
تازه‌سازی خودکار به‌روزرسانی خودکار viewها با فاصله قابل تنظیم
پشتیبانی از Git Commands checkout, merge, delete, tag, push, pull
خطاگیری نمایش خطاهای DomainError با کدهای مناسب
گزارش‌دهی خروجی کامل در Output Channel
